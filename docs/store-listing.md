# Google Play Store 등록 정보

## 앱 이름
링크 노트

## 짧은 설명 (80자 이내)
공유 버튼 한 번으로 링크 저장! AI가 자동으로 요약, 태그, 카테고리 정리까지.

## 긴 설명 (4000자 이내)

링크 노트는 여기저기 흩어진 링크를 한곳에 모아 AI가 자동으로 정리해주는 앱입니다.

YouTube, Instagram, Threads, X(Twitter), TikTok, 웹사이트 등 어디서든 공유 버튼 한 번이면 링크가 자동 저장됩니다. 저장된 링크는 AI가 자동으로 요약하고 태그를 달고 카테고리를 분류해주어, 나중에 쉽게 찾아볼 수 있습니다.

▶ 원클릭 저장
다른 앱에서 공유 버튼을 누르고 '링크 노트'를 선택하면 끝. 제목, 썸네일, 요약까지 자동으로 가져옵니다.

▶ AI 자동 정리
- 링크 내용을 읽고 핵심 요약을 생성합니다
- 관련 태그 5개를 자동으로 추출합니다
- 개발, 투자, 건강, 교육, 엔터테인먼트, 뉴스, 라이프스타일 등 8가지 카테고리로 자동 분류합니다

▶ 플랫폼별 필터
YouTube만 모아보기, Instagram만 모아보기 등 매체별로 필터링할 수 있습니다.

▶ 카테고리별 필터
관심 주제별로 저장한 링크를 빠르게 찾아볼 수 있습니다.

▶ 간편한 관리
- 저장한 링크의 상세 정보를 한눈에 확인
- 원본 링크로 바로 이동
- 친구에게 공유하기
- 필요 없는 링크는 바로 삭제

▶ 안전한 계정 관리
- 이메일 가입 또는 Google 간편 로그인
- 클라우드 동기화로 기기 변경 시에도 데이터 유지

나중에 보려고 저장한 링크, 이제 잃어버리지 마세요. 링크 노트가 대신 정리해드립니다.

## English Store Listing (for international reach)

### App Name
LinkNote

### Short Description (80 chars max)
Save any link with one tap! AI auto-summarizes, tags, and categorizes for you.

### Long Description

LinkNote gathers all your scattered links in one place and lets AI organize them automatically.

From YouTube, Instagram, Threads, X (Twitter), TikTok, or any website — just tap Share and select LinkNote. Every saved link gets an AI-generated summary, auto-tags, and category classification so you can find it later with ease.

▶ One-Tap Save
Hit share from any app, pick LinkNote — done. Title, thumbnail, and summary are fetched automatically.

▶ AI Auto-Organization
- Reads link content and generates a concise summary
- Extracts 5 relevant tags automatically
- Classifies into 8 categories: Development, Investing, Health, Education, Entertainment, News, Lifestyle, and more

▶ Platform Filters
View only YouTube links, only Instagram links, etc. Filter by source platform instantly.

▶ Category Filters
Browse saved links by topic to quickly find what you need.

▶ Easy Management
- View full details of any saved link at a glance
- Jump to the original link
- Share with friends
- Delete links you no longer need

▶ Secure Account
- Sign up with email or Google login
- Cloud sync keeps your data safe across devices

Stop losing links you saved "for later." LinkNote organizes them for you.

## 스크린샷 촬영 가이드

### 필요 스크린샷 (최소 4장, 권장 8장)

| # | 화면 | 설명 | 촬영 방법 |
|---|------|------|----------|
| 1 | **홈 화면** | 링크 카드 목록이 여러 개 보이는 상태 | 앱 실행 → 홈에서 캡처 (최소 5개 링크 저장된 상태) |
| 2 | **공유 저장** | 다른 앱에서 공유 → 링크 노트 선택 | YouTube 등에서 공유 버튼 → 링크 노트 → 저장 완료 토스트 |
| 3 | **링크 상세** | 요약, 태그, 카테고리가 보이는 상세 화면 | 링크 카드 탭 → 상세 화면 캡처 |
| 4 | **플랫폼 필터** | 필터 칩으로 YouTube만 필터링된 상태 | 홈 → YouTube 칩 선택 → 캡처 |
| 5 | **카테고리 필터** | 주제별 필터 적용된 상태 | 홈 → 카테고리 칩 선택 → 캡처 |
| 6 | **로그인 화면** | 이메일 + Google 로그인 | 로그아웃 → 로그인 화면 캡처 |
| 7 | **다양한 플랫폼** | Instagram, Threads, X 등 다양한 링크 | 여러 플랫폼 링크 저장 후 캡처 |
| 8 | **빈 화면 → 저장 후** (선택) | Before/After 비교 | 빈 홈 → 링크 추가 → 캡처 |

### 스크린샷 규격
- **해상도**: 기기 기본 해상도 (최소 320px, 최대 3840px)
- **비율**: 16:9 세로 권장
- **형식**: PNG 또는 JPEG
- **상태바**: 포함해도 되지만, 깔끔하게 크롭 권장

### 프로모 배너 (1024x500)
- 앱 아이콘 + 핵심 기능 텍스트 조합
- 추천 문구: "링크 저장은 한 번 탭, 정리는 AI가" 또는 "Save links. AI does the rest."
- Canva, Figma 등으로 제작 가능
