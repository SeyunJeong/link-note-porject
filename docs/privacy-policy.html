개인정보처리방침

시행일: 2026년 2월 17일

링크 노트(이하 "앱")는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 개인정보처리방침은 앱이 수집하는 정보, 이용 목적, 보관 기간 등을 안내합니다.

1. 수집하는 개인정보 항목

항목 수집 목적 보관 기간
이메일 주소 회원가입 및 로그인 회원 탈퇴 시까지
비밀번호 (암호화 저장) 계정 인증 회원 탈퇴 시까지
Google 계정 정보 (선택) 소셜 로그인 회원 탈퇴 시까지
저장한 링크(URL) 핵심 서비스 제공 사용자 삭제 또는 탈퇴 시까지
링크 메타데이터 (제목, 썸네일, 설명) 링크 정보 표시 해당 링크 삭제 시까지
AI 생성 요약, 태그, 카테고리 링크 정리 및 검색 편의 해당 링크 삭제 시까지
앱은 위치 정보, 연락처, 사진, 기기 식별자 등 민감한 개인정보를 수집하지 않습니다. 별도의 분석(Analytics) 또는 광고 추적 도구를 사용하지 않습니다.

2. 개인정보의 이용 목적

  • 회원 관리: 가입, 로그인, 본인 확인
  • 서비스 제공: 링크 저장, 메타데이터 추출, AI 기반 요약 및 태그 생성
  • 서비스 개선: 오류 수정 및 안정성 향상

3. 제3자 제공 및 위탁

앱은 서비스 운영을 위해 다음 외부 서비스를 이용합니다.

서비스 제공 업체 전달 정보 목적
인증 및 데이터베이스 Supabase (미국) 이메일, 비밀번호(암호화), 저장된 링크 데이터 사용자 인증 및 데이터 저장
AI 분석 OpenAI (미국) 링크의 제목 및 설명 (최대 500자) 요약, 태그, 카테고리 자동 생성
서버 호스팅 Railway (미국) API 요청 데이터 백엔드 서버 운영

OpenAI에 전달되는 데이터는 링크의 제목과 설명 텍스트에 한정되며, 사용자의 이메일 등 개인 식별 정보는 전달하지 않습니다.

4. 개인정보의 보관 및 파기

  • 사용자가 링크를 삭제하면 관련 데이터는 즉시 삭제됩니다.
  • 회원 탈퇴 시 모든 개인정보 및 저장 데이터를 지체 없이 파기합니다.
  • 법령에 의해 보존이 필요한 경우 해당 기간 동안 별도 보관 후 파기합니다.

5. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람권: 저장된 개인정보를 확인할 수 있습니다.
  • 수정권: 부정확한 정보의 수정을 요청할 수 있습니다.
  • 삭제권: 저장된 링크를 자유롭게 삭제할 수 있습니다.
  • 탈퇴권: 언제든 회원 탈퇴를 통해 모든 데이터를 삭제할 수 있습니다.

6. 기기 내 저장 정보

앱은 로그인 상태 유지를 위해 기기에 인증 토큰을 저장합니다. 로그아웃 시 기기에 저장된 토큰은 즉시 삭제됩니다. 쿠키 또는 별도의 추적 기술은 사용하지 않습니다.

7. 보안 조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • 비밀번호는 암호화하여 저장되며, 원문 복원이 불가능합니다.
  • 사용자 데이터는 계정별로 격리되어 다른 사용자가 접근할 수 없습니다.
  • 인증 토큰은 JWT 방식으로 유효 기간이 제한됩니다.

8. 아동의 개인정보 보호

앱은 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 만 14세 미만임이 확인된 경우 해당 계정과 데이터를 즉시 삭제합니다.

9. 개인정보처리방침 변경

본 방침이 변경되는 경우, 앱 내 공지 또는 이메일을 통해 사전 안내합니다. 변경된 방침은 공지 후 7일이 경과한 시점부터 효력이 발생합니다.
